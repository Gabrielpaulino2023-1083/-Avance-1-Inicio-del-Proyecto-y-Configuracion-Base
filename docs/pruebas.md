# Pruebas del sistema

## Estructura inicial

Para preparar el proyecto para las siguientes etapas del desarrollo, se creó la carpeta `tests/`, organizada en tres categorías:

- `unit/`: pruebas unitarias de componentes o funciones individuales.
- `integration/`: pruebas de comunicación entre los diferentes módulos del sistema.
- `functional/`: pruebas del comportamiento general de las funcionalidades desde la perspectiva del usuario.

En esta primera entrega las carpetas se mantienen preparadas para incorporar las pruebas automatizadas conforme se desarrollen las funcionalidades del sistema.
