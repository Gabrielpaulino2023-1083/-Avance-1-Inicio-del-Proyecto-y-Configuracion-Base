# Motor de Aprendizaje Adaptativo

## Descripción

Proyecto de desarrollo de una plataforma educativa basada en un
motor de aprendizaje adaptativo que analiza el comportamiento
y desempeño del estudiante.

La plataforma utilizará información como el tiempo de estudio,
errores, repeticiones y navegación para adaptar contenidos,
actividades y nivel de dificultad según las necesidades de cada estudiante.

## Tecnologías que se emplearan

- React.js
- TypeScript
- Node.js
- Express.js
- PostgreSQL
- Python
- Pandas
- Scikit-learn
